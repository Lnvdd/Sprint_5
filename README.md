Sprint 5 
Этот репозиторий содержит набор автотестов для проверки ключевых пользовательских сценариев на сайте Stellar Burgers.

Протестированы функции:
Тестирование регистрации и авторизации пользователей
Проверка обработки ошибок при вводе неправильных данных
Навигация по главной странице и личному кабинету
Проверка операций перехода между разделами конструктора («Булки», «Соусы», «Начинки»)
Проверка выхода из профиля

Запустите все тесты:
python -m pytest
